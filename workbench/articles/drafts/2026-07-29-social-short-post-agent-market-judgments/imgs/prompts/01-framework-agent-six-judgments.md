关于 Agent 的六个判断 — Conceptual Framework

Create a single-page Chinese editorial framework poster. The framework must communicate a progression from market structure to product advantage, then to individual and startup action. It should be understandable at a glance, with very little text.

STRUCTURE: A bold hierarchical framework with one central Agent symbol and six numbered nodes arranged in two horizontal tiers. The upper tier contains four market and product judgments. The lower tier contains two action judgments. Strong downward visual flow connects analysis to action.

ZONES:

- TOP TITLE ZONE: Large integrated Chinese title 关于 Agent 的六个判断. Add a small subtitle 从行业格局到行动机会.
- CENTER FOCAL ZONE: A bold geometric Agent core, represented as a compact abstract command center or intelligent node, not a humanoid robot. Surround it with subtle concentric rings suggesting platform reach.
- UPPER TIER, NODE 1: Number 1 and label 少数通用 Agent 通吃. Symbolic image of one large central platform absorbing several small app tiles.
- UPPER TIER, NODE 2: Number 2 and label 插件系统更重要. Symbolic modular plugs labeled Skill and MCP connecting capabilities into the Agent core.
- UPPER TIER, NODE 3: Number 3 and label 前期主要教育用户. Symbolic path where users move from 小龙虾 and WorkBuddy toward Codex and Claude Code. Keep brand names as small, legible keywords only.
- UPPER TIER, NODE 4: Number 4 and label 模型是最大护城河. Symbolic intelligence core protected by a moat, with two keywords 智能 and 成本.
- LOWER TIER, NODE 5: Number 5 and label 越早使用越受益. Symbolic human operator giving four compact inputs to an Agent, labeled 目标, 上下文, 边界, 验收.
- LOWER TIER, NODE 6: Number 6 and label 小团队做 Agent 原生应用. Symbolic transformation from APP 按钮 to 持续交付结果, ending in a compact outcome box labeled 对结果负责.
- BOTTOM TAKEAWAY: One short Chinese sentence integrated into the poster, 平台会集中，新的应用机会仍在生长.

RELATIONSHIPS:

- Nodes 1–4 form the competitive foundation around the central Agent core.
- A bold downward arrow labeled 从判断到行动 connects the upper tier to Nodes 5–6.
- Node 5 represents how individuals benefit; Node 6 represents where small teams should build.
- Keep all connectors visually simple, thick, and directional. Avoid a dense network.

LABELS: 关于 Agent 的六个判断; 从行业格局到行动机会; 1 少数通用 Agent 通吃; 2 插件系统更重要; Skill; MCP; 3 前期主要教育用户; 小龙虾; WorkBuddy; Codex; Claude Code; 4 模型是最大护城河; 智能; 成本; 5 越早使用越受益; 目标; 上下文; 边界; 验收; 6 小团队做 Agent 原生应用; APP 按钮; 持续交付结果; 对结果负责; 从判断到行动; 平台会集中，新的应用机会仍在生长.

COLORS: Warm-only palette. Soft Peach #FFECD2 background, Deep Charcoal #2D2D2D for silhouettes and strong structure, Warm Orange #ED8936 for the central Agent and primary emphasis, Terracotta #C05621 for market nodes, Golden Yellow #F6AD55 for action nodes, Deep Brown #744210 for grounding and typography. No green, blue, or purple. Color values and color names are rendering guidance only — do NOT display color names, hex codes, or palette labels as visible text in the image.

STYLE: Screen print / silkscreen editorial poster art. Flat color blocks, no gradients. Halftone dot patterns, subtle warm paper grain, slight color-layer misregistration, stencil-cut edges, bold silhouettes, geometric framing, and generous negative space. Use 5 colors maximum. Typography should be bold condensed Chinese sans-serif integrated into the composition, not floating over it. Keep all Chinese text large, minimal, correctly spelled, and highly legible. No photorealism, no detailed faces, no 3D rendering, no glossy UI mockups, no decorative clutter.

COMPOSITION: Clean, centered, symmetrical, with generous margins and clear separation between the upper competitive tier and lower action tier. Simple background. The central Agent symbol is the dominant visual anchor. Each numbered node must be distinct and readable on a social-media feed.

ASPECT: 16:9, 2K, medium-low visual complexity, optimized for Chinese social media article illustration.
