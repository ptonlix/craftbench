# 微信想让 AI 操作小程序，但未来的入口可能根本不在微信

![个人 Agent 成为用户入口，微信与其他应用退到后台服务层](imgs/01-scene-agent-super-entry-v2.png)

微信对 AI 的想象，似乎仍停留在自己的一亩三分地里。

用户打开微信，微信 AI 再替用户调用小程序。这个设想藏着一个必要的前提，未来的人还会主动打开微信。

我觉得未必。

以后年轻人可能不会点进微信群翻记录，而是直接对自己的 Agent 说，帮我总结昨天的群聊，再给我妈发条消息，晚上不回家吃饭。

谁接住并执行了这句话，谁才是超级入口。

而它大概率不是微信 AI。

## Agent 抢的是用户心智

这一波 Agent 从效率场景长出来，编程、办公，再泛化到生活。Codex、Claude Code 正在训练用户把任务直接交出去，而不是自己找入口、开应用、点按钮。

微信最擅长的却是社交和生活。订机票、选酒店这些事看似简单，背后要理解模糊需求、比较价格、调用多个服务，还要在付款前让人确认。微信 AI 现在未必处理得好。

等其他 Agent 在工作里抢占用户心智，它们自然会进入生活。用户不会为发消息换一个 Agent，为订酒店再换另一个，只会倾向于使用那个最懂自己、记得自己偏好的 Agent。

## 小程序很难复制 Skills 的进化方式

一个 Skill 用起来不顺手，Agent 可以直接读代码、改脚本、重新运行。你也可以按自己的习惯继续调整，今天改一点，明天再改一点，最后它会越来越贴合你。

小程序就不行了。它背后是开发者，前面还有打包、提交、审核这一整套流程。Agent 在使用时发现问题，最多只能把问题报上去，不可能像改 Skill 一样当场改、当场试。

而且 Agent 擅长接口和脚本，不擅长反复点击图形界面。除非微信把小程序开放得像 CLI 一样直接，否则调用成本、Token 消耗和成功率都不会好看。

小龙虾能火，恰恰因为它敢拿权限，有长期运行的电脑，还能现场写脚本、反复尝试，大力出奇迹。微信 AI 既缺少手机权限，也没有稳定执行环境，更未必愿意为一次生活烧掉大量 Token。

## 微信未来预测

微信当然还握着最强的社交关系链，但未来用户可能不会再通过微信发起任务，而是先把需求告诉自己的 Agent，再由 Agent 去调用微信。

微信一直想成为操作系统，但它终究只是手机系统上的超级应用。它可以拒绝豆包手机访问自己，未来却可能发现，用户已经不再亲自打开微信了。

回旋镖已经飞出去了。

微信要防的不是另一个更大的 App，而是那个替用户操作所有 App 的 Agent。
