为一篇中文社交媒体观点文章创作一张科技感编辑插画宣传主视觉。

画面必须表达一个非常明确的层级，用户只面对个人 Agent，个人 Agent 是唯一入口，微信、小程序和其他 App 只是后方被调用的服务。

LAYOUT

- 16:9 横向科技媒体文章封面，简洁、醒目、带有观点冲突
- 左侧是一位年轻用户的简化侧身剪影，正在对画面中央的个人 Agent 发出自然语言任务
- 中央是唯一的大型视觉核心，一个稳定清晰的个人 Agent 数字中枢，尺寸最大，亮度最高，但不能过曝
- 右侧远处是明显更小、更暗、更弱的后台服务节点，包含聊天气泡、小程序方块、酒店、机票、办公和其他 App 的抽象图标
- 微信聊天节点必须只是众多后台节点中的一个，尺寸不超过个人 Agent 核心的四分之一，不能与 Agent 并列，不能占据画面视觉中心
- 所有后台服务只通过细连接线接入个人 Agent，不直接连接用户
- 右侧保留充分间距，图标数量控制在 5 个以内，不能拥挤
- 画面四周和顶部必须保持干净，不要放任何装饰文字、字母、数字、代码、符号串或伪 UI

ZONES

- 左侧用户区，用户只和 Agent 对话
- 中央唯一入口区，个人 Agent 统筹所有任务
- 右侧后台服务区，微信、小程序和其他 App 缩小并后退，成为可调用能力

TEXT

- 整张图片不要出现任何文字、汉字、英文字母、数字、Logo 字样、代码或界面标签
- 不要生成标题，不要生成角标，不要生成水印，不要生成伪文字
- 只靠构图、图标层级和连接关系表达含义

COLORS

- 暖桃色纸张背景 #FFECD2
- 暖橙色 #ED8936 用于个人 Agent 核心和主连接线
- 陶土色 #C05621 用于后台服务节点
- 金黄色 #F6AD55 用于任务流和局部高光
- 深棕色 #744210 与深炭色 #2D2D2D 用于轮廓、网格和人物剪影
- 全画面只使用暖色，不要出现蓝色、绿色和紫色
- 色值只用于渲染，不得出现在画面中

STYLE

- 科技编辑插画与精密系统蓝图结合，干净几何结构、细线网格、清楚节点关系
- 现代但不要廉价赛博朋克，不要霓虹城市，不要复杂 HUD，不要照片感
- 暖色纸张纹理与轻微印刷颗粒，像有观点的科技杂志封面
- 人物使用简化剪影，不要写实脸部
- 不要精确复制微信官方 Logo，用抽象双聊天气泡代表聊天服务，并让它与其他服务图标处于同一层级
- Central Agent glow must retain visible edges and internal structure, no blown highlights
- Clean composition with generous white space and a clear left-to-right reading path

MOOD

- 入口权力正在悄悄迁移，带一点警醒，但不是灾难或反乌托邦

ASPECT

16:9，2K，横向社交媒体文章封面，单一主视觉，中等复杂度。
