为一篇中文社交媒体观点文章创作一张科技感编辑插画宣传主视觉。

核心概念

未来用户不再主动打开微信，而是先把需求交给自己的个人 Agent，再由 Agent 调用微信、小程序和其他 App。真正的超级入口从 App 转移到了 Agent。

LAYOUT

- 16:9 横向构图，像科技媒体的文章封面，简洁、有冲突、有传播感
- 前景左侧是一位年轻用户的简化侧身剪影，面向画面中心，用自然语言向个人 Agent 下达任务
- 画面中心是明亮、稳定、具有主导地位的个人 Agent 智能核心，像一个悬浮的数字控制中枢，不要画成人形机器人
- 背景右侧和远处排列多个退居二线的服务节点，包括微信聊天气泡、小程序方块、酒店、机票、办公和其他 App 的抽象图标
- 从个人 Agent 核心向后台服务延伸清晰连接线，表现 Agent 在替用户调用这些应用
- 用空间层级明确表现，用户首先面对 Agent，微信只是 Agent 背后的一个服务节点
- 留出足够负空间，避免堆满界面和图标

ZONES

- 左侧用户区，年轻用户只和 Agent 交流，不直接触碰任何 App
- 中央入口区，个人 Agent 占据视觉中心，尺寸最大、亮度最高，像新的超级入口
- 右侧后台服务区，微信和小程序仍然重要，但视觉尺寸更小、更远，被 Agent 统一调度
- 底部可加入极简的任务流光轨迹，从一句需求流向多个服务结果

LABELS

- 只允许出现两个简短、清晰的中文标签，个人 Agent、微信
- 不要出现文章长标题，不要出现大段文字，不要生成乱码
- 标签若无法保证准确，可以完全不显示文字，只通过构图表达概念

COLORS

- 暖桃色纸张背景 #FFECD2
- 暖橙色 #ED8936 用于个人 Agent 的核心光源和主连接线
- 陶土色 #C05621 用于后台服务节点
- 金黄色 #F6AD55 用于任务流和局部高光
- 深棕色 #744210 与深炭色 #2D2D2D 用于轮廓、网格和人物剪影
- 全画面只使用暖色，不要出现蓝色、绿色和紫色
- 颜色名称和色值只用于渲染，不得作为画面文字出现

STYLE

- 科技编辑插画与精密系统蓝图结合，干净的几何结构、细线网格、清楚的节点关系
- 现代但不要廉价赛博朋克，不要霓虹城市，不要复杂 HUD，不要照片感
- 暖色纸张纹理与轻微印刷颗粒，让画面更像有观点的科技杂志封面
- 人物使用简化剪影或象征性造型，不要写实脸部
- 不要使用微信官方 Logo 的精确复制，可使用能让人联想到聊天应用的绿色以外抽象双气泡符号，但必须保持暖色调
- Clean composition with generous white space. Simple background. Main elements positioned by content needs.

MOOD

- 带一点警醒和未来正在逼近的感觉
- 不是灾难，不是反乌托邦，而是入口权力正在悄悄迁移

ASPECT

16:9，2K，横向社交媒体文章封面，单一主视觉，中等复杂度。
