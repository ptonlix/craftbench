《模型越强，生意越脆弱》社交媒体文章封面主视觉。

LAYOUT:
- 16:9 横版，中心对称的丝网印刷编辑海报构图。
- 画面中央是一枚由抽象神经网络线路和芯片轮廓构成的巨大火箭，代表不断刷新能力的大模型，强势向上穿出画面。
- 火箭下方不是普通发射台，而是由 TOKEN、API 两块几何模块搭成的商业基座。基座出现明显裂缝，碎片向下掉落。
- 利用负空间，让裂缝和掉落碎片共同形成一条向下的收入曲线，表达性能上升与商业价值下滑同时发生。
- 右上角用三个很小的速度残影标签表示模型快速轮替，只写 GLM 5.2、DeepSeek V4、Kimi K3。
- 60% 以上留白或低信息区域，主视觉集中，适合社交媒体封面裁切。

ZONES:
- 顶部标题区，只保留一句醒目的中文标题“模型越强，生意越脆弱”。
- 中部主视觉区，网络火箭向上，TOKEN 与 API 基座开裂。
- 底部结论区，只保留短句“用户切换成本趋近于零”。

LABELS:
- 模型越强，生意越脆弱
- GLM 5.2
- DeepSeek V4
- Kimi K3
- TOKEN
- API
- 用户切换成本趋近于零

COLORS:
- 暖奶油纸张背景 #F5E6D0。
- 焦橙 #E8751A 表示高速增长的模型能力。
- 深棕 #4A2A1A 表示商业基座、文字和阴影。
- 绯红 #C0392B 只用于裂缝、风险和下行曲线。
- 琥珀 #F4A623 用于极少量高光。
- 色值与颜色名称仅用于渲染指导，绝对不要把色值或颜色名称画成可见文字。

STYLE:
- 复古 screen-print / silkscreen 编辑海报，扁平色块，绝对不要渐变。
- 半色调网点、纸张颗粒、轻微套色错位，带 1970 年代商业杂志封面质感。
- 粗壮剪影、模板切割边缘、几何框架，不要写实，不要复杂背景。
- 中文字体应是粗窄无衬线海报字，融入构图，不像后期覆盖。
- 所有文字必须准确、醒目、易读，只使用上面列出的短标签，不添加英文副标题或乱码。
- Clean composition with generous white space. Simple background. Main elements centered by content needs.

ASPECT: 16:9，2K，信息复杂度中低，社交媒体封面。
