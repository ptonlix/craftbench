# Vibe Coding 创造成本与拥有成本短文

这篇短文的核心判断是：AI Coding 让软件第一版变得便宜，但没有让长期拥有软件的责任消失。

## 核心观点

- “能做出来”和“值得长期拥有”是两件不同的事。
- 软件进入维护期后，成本会转向权限、迁移、依赖升级、监控、备份、安全与故障恢复。
- AI 擅长局部修改，但系统仍需要明确的所有者承担整体责任。
- 自研适合边界清晰、复杂度可控且团队愿意长期维护的能力；通用复杂能力通常更适合购买成熟产品。

这组判断补充了 [[concepts/vibe-coding]] 的长期维护边界，也与 [[concepts/ai-code-quality-gates]] 强调的可执行质量控制相呼应。^[inferred]
