# Published Articles 2026-07-29 to 08-11

这批文章从产品、协议、组织、商业和科研五个层面观察 Agent 的扩张：通用平台通过模型与插件生态吸收垂直能力；MCP 向无状态生产基础设施演进；企业落地从工程攻坚延伸到组织运营；应用入口可能从 App 转向个人 Agent；强模型科研则把人的工作推向目标设定、探索组织和验证。

## Key Ideas

- Agent 平台的能力宽度来自 Skill 与 MCP 等扩展生态，任务质量仍显著受模型智能与成本影响。
- MCP 2026-07-28 版本以自包含请求、显式状态句柄和标准 HTTP 运维能力降低横向扩容成本。
- FDE 解决系统进入企业的问题，AIBP 则负责业务采用、流程改造和结果运营，两者是连续分工而非替代关系。
- AI 商业闭环需要把智能输出稳定转化为交付、付款和复购，并覆盖模型、获客和人工交付成本。
- 如果个人 Agent 能统一理解偏好并调用服务，微信和其他 App 可能从用户入口退到能力层。^[inferred]
- AI 科研协作中，人类价值正从逐步求解转向定义问题、维持探索、组织验证和承担结论责任。^[inferred]
