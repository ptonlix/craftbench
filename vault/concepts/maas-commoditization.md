# MaaS Commoditization

模型能力持续刷新，但用户切换模型往往只需更换 API 或修改少量配置。低迁移成本削弱用户忠诚，使单纯出售 token 和 API 的 MaaS 面临价格下降与资本开支上升的双重压力。

## Economic Tension

- 新模型不断成为短期首选，上一代模型很快退居备选。
- 用户会追逐更强、更快、更便宜的模型，没有长期绑定单一供应商的必要。
- 收入端承受持续降价，成本端却必须投入训练与推理算力。
- 前一代训练成本尚未回收，下一代研发和训练已经启动。
- 模型能力可能逐渐接近云计算中的标准资源：重要，但难以长期享受高溢价。 ^[inferred]

## Value Migration

把模型嵌入 ERP、CRM 或旧流程可以降本增效，但这类项目仍可能争夺有限的 IT 预算，并受到投入产出比压价。更高价值的方向是创造过去无法成立的新场景，让客户形成新增收入来源，并按新增价值付费。 ^[inferred]
