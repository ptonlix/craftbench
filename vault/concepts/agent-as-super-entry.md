# Agent as Super Entry

超级入口的竞争对象可能从“用户打开哪个 App”变成“用户先把任务交给谁”。个人 Agent 若能理解长期偏好并安全调用多个服务，就可能成为统一意图入口。^[inferred]

## Key Ideas

- 用户倾向于把跨工作与生活的任务交给一个持续理解自己的 Agent，而不是为每类任务切换助手。^[inferred]
- Skill 可被 Agent 读取、修改和即时重试，小程序则受到开发、打包、审核和图形交互约束。
- 微信仍拥有关系链和服务生态，但可能从前台入口退为 Agent 调用的后台能力。^[inferred]
- 真正落地仍依赖身份、授权、支付、确认、责任和稳定执行环境。^[inferred]
