# Agent Platform Concentration

通用 Agent 接入 Skill 和 MCP 后可以持续补齐专业能力，使许多垂直 Agent 逐渐变成平台内的一项能力。平台的宽度来自生态，体验上限则受模型智能和使用成本约束。

## Key Ideas

- 插件生态是否开放、繁荣且可迁移，比单纯允许切换模型更能决定平台承接专业任务的能力。
- 早期入口型产品承担用户教育，但当更强、更便宜的平台出现时，迁移成本可能较低。
- 小团队更适合设计 Agent 原生的持续工作与结果交付，而不是复制通用平台。^[inferred]
